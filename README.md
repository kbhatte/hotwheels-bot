# Hot Wheels availability monitor

This repository checks available Hot Wheels listings from Blinkit, Zepto, and Instamart during the configured morning window and sends Telegram alerts.

## Privacy

The delivery coordinates are never stored in source code. Add them as GitHub Actions secrets named `DELIVERY_LATITUDE` and `DELIVERY_LONGITUDE`. Request headers, session tokens, and request bodies must also be stored as secrets.

## Telegram setup

1. In Telegram, open `@BotFather`.
2. Send `/newbot`, choose a name and username, and copy the token.
3. Send a message to the new bot.
4. Open `https://api.telegram.org/bot<TOKEN>/getUpdates` and copy the numeric `chat.id`.
5. Add `TELEGRAM_BOT_TOKEN` and `TELEGRAM_CHAT_ID` as GitHub Actions secrets.

## GitHub configuration

Add these repository secrets under **Settings > Secrets and variables > Actions > Secrets**:

- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`
- `DELIVERY_LATITUDE`
- `DELIVERY_LONGITUDE`
- `BLINKIT_HEADERS`
- `BLINKIT_BODY` (only if needed)
- `ZEPTO_HEADERS`
- `ZEPTO_BODY` (only for a POST request)
- `INSTAMART_HEADERS`
- `INSTAMART_BODY` (only for a POST request)

Add these as Actions variables when known: `ZEPTO_SEARCH_URL`, `ZEPTO_METHOD`, `INSTAMART_SEARCH_URL`, and `INSTAMART_METHOD`. Methods are `GET` or `POST`.

URLs and JSON bodies may contain `${LATITUDE}`, `${LONGITUDE}`, and `${SEARCH_TERM}` placeholders. They are substituted only at runtime.

## Capturing provider requests

Use each provider website or app while the delivery location is selected. In browser developer tools, open **Network**, search for `hot wheels`, and identify the request returning product data. Copy its URL, method, request headers, and JSON body. Remove unnecessary tracking headers, then store the remaining JSON in the matching secret. Repeat when a provider changes its API.

The providers are independent. A failed or unconfigured provider does not mark its old products unavailable.

## New and restocked listings

`listing_state.json` is generated by the workflow and ignored by Git. A listing alerts when it is first observed as available or when it was previously unavailable and becomes available again. Products that disappear from a successful provider response are marked unavailable. A failed provider response does not change state.

## Schedule

The workflow runs at 01:30 through 06:30 UTC, which is 07:00 through 12:00 IST. Use **Actions > Hot Wheels Drop Tracker > Run workflow** for a manual test.
